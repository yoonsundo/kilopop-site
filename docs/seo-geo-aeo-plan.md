# 킬로팝 사이트 검색 노출 설계 (SEO · AEO · GEO)

> 작성 2026-10-30. 이 설계대로 구현했다(`src/`, `scripts/build.mjs`, 검사는 `scripts/check.mjs`). 3장의 영어 페이지와 7장의 정할 것은 아직 열려 있다.
> 용어: SEO는 검색엔진 최적화, AEO는 검색 결과의 답변 상자·음성 비서가 바로 인용하게 만드는 일, GEO는 ChatGPT·Perplexity·Gemini 같은 생성형 AI가 답할 때 출처로 인용하게 만드는 일이다.

## 1. 결론

랜딩 한 장에 메타 태그를 붙이는 것으로는 부족하다. 실제 검색어마다 답을 맡을 페이지를 하나씩 두고(4쪽), 모든 글이 자바스크립트 없이 HTML에 들어 있게 미리 만든다. 구조화 데이터는 화면에 보이는 내용과 똑같이 넣는다.

구글은 2026년 5월 안내서에서 AI 검색 노출도 결국 일반 검색과 같은 색인·순위 체계를 쓴다고 밝혔다. 그래서 AEO·GEO도 '좋은 SEO + 직접 답하는 글 구조 + 1차 경험'이 핵심이고, AI 전용 파일이나 표시는 보조로만 둔다.

## 2. 검색어 조사 (2026-10-30, 네이버·구글 자동완성)

| 묶음 | 실제 자동완성 검색어 | 맡을 페이지 |
|---|---|---|
| 앱 찾기 | 러닝 인증샷 어플, 러닝 인증 앱, 러닝 인증샷 앱, 인스타 러닝 인증 앱, 러닝 스토리 앱 | `/` |
| 방법 찾기 | 러닝 인증샷 만들기, 러닝 인증샷 만드는 방법, 런닝 인증샷 만드는 방법, 사진에 러닝 기록 넣기, 러닝 기록 사진 넣는방법, 러닝 기록 사진 합성·편집·꾸미기 | `/guide/running-photo/` |
| 스토리 | 러닝 스토리 꾸미기, 러닝 스토리 올리는 법, 러닝 인스타 스토리 꾸미기, 러닝 인증 스토리 | `/guide/running-photo/`의 스토리 절 |
| 기록 앱별 | 나이키 러닝 인증샷, 가민 러닝 인증샷, 스트라바 인증샷 올리는법, 나이키 런클럽 인증 방법 | `/` 자주 묻는 질문 + 안내서의 한 절 |
| 대회 | 마라톤 인증샷, 마라톤 완주 인증샷 | 자주 묻는 질문 |
| 템플릿 | 러닝 기록 템플릿, 러닝 인증샷 편집 | `/templates/` |

- 경쟁: 앱 스토어에서 '러닝 인증'으로 찾으면 나오는 기록 꾸미기 앱들은 모두 설치형이고, 일부는 로그인이 필요하다. '설치·로그인 없이 브라우저에서 바로'가 검색 결과에서 내세울 차별점이다.
- 검색량 수치는 네이버 검색광고 키워드 도구(로그인 필요)로 구현 전에 한 번 더 확인한다.

## 3. 페이지 구조

| 주소 | 제목(title) | 노리는 질문 | 구조화 데이터 |
|---|---|---|---|
| `/` | 러닝 인증샷 어플, 설치 없이 바로 만들기 \| 킬로팝 | 러닝 인증샷 어플이 뭐가 있어? | WebSite, Organization, WebApplication, FAQPage |
| `/guide/running-photo/` | 사진에 러닝 기록 넣기: 러닝 인증샷 만드는 법 \| 킬로팝 | 사진에 러닝 기록 어떻게 넣어? 러닝 스토리 어떻게 꾸며? | Article, HowTo, WebApplication, BreadcrumbList |
| `/templates/` | 러닝 기록 템플릿 4종: 인스타 스토리 인증샷 \| 킬로팝 | 러닝 기록 템플릿 어떤 게 있어? | CollectionPage, ItemList(ImageObject), WebApplication, BreadcrumbList |
| `/privacy/` | 개인정보 처리방침 \| 킬로팝 | (신뢰 신호. 나중에 인스타 스토리 직행에 필요한 공개 주소) | WebPage |
| `/404.html` | 페이지를 찾을 수 없어요 | - | - |

- 같은 내용을 검색어별로 찍어 내는 페이지는 만들지 않는다. 구글 스팸 정책(대량 생산 콘텐츠)에 걸린다.
- 영어 페이지(`/en/`)는 지금 만들지 않는다. 해외 사용자를 받기로 하면 hreflang과 함께 더한다.

## 4. 글 쓰는 규칙 (AEO · GEO)

1. 첫 문단에 정의 문장을 둔다: "킬로팝은 사진 위에 러닝 기록을 얹어 인스타 스토리용 인증샷(1080×1920)을 만드는 무료 웹앱이에요." AI가 이름과 하는 일을 한 문장으로 인용할 수 있다.
2. 자주 묻는 질문은 사람들이 실제로 치는 질문을 소제목으로 쓰고, 바로 아래 첫 한두 문장에서 답을 끝낸다. 안내서·템플릿은 소제목에 검색어를 넣고(예: '글자·스티커로 러닝 스토리 꾸미기'), 각 쪽 첫 문단(`.answer`)에서 답을 먼저 준다.
3. 숫자와 사실을 구체적으로 쓴다: 1080×1920, 9:16 JPEG, 템플릿 4종, 0원, 로그인 없음, 서버 업로드 없음.
4. 1차 경험을 넣는다: 시험 배포본에서 직접 찍은 화면, 앱이 실제로 저장한 결과물, 만든 사람이 왜 만들었는지.
5. 이름 표기를 한 가지로 맞춘다: 한글 '킬로팝', 영문 'Kilopop'(로고 표기 KILOPOP). 구조화 데이터의 `alternateName`에 둘 다 넣는다.
6. 확인되지 않은 주장은 쓰지 않는다: '1분 완성' 같은 시간 주장, 안드로이드 저장 보장(실기기 확인 전), 평점·사용자 수.

## 5. 기술 장치

- 정적 HTML 미리 생성: 모든 글과 링크가 HTML에 들어 있다. AI 크롤러 상당수가 자바스크립트를 실행하지 않기 때문이다.
- 메타: title, description(한글 80자 안팎), canonical, Open Graph(카카오톡·네이버 미리보기용 1200×630 이미지), Twitter 카드, `og:locale=ko_KR`, theme-color.
- 구조화 데이터(JSON-LD @graph): 화면에 보이는 내용만 넣는다. 평점(aggregateRating)처럼 근거 없는 값은 넣지 않는다. 구글은 FAQ 리치 결과를 정부·건강 사이트로 줄였고 HowTo 리치 결과는 끝냈지만, 페이지 내용을 기계가 읽게 하는 용도로 둔다.
- robots.txt: 검색 크롤러(Googlebot, 네이버 Yeti, 다음 Daumoa, Bingbot)와 AI 검색 크롤러(OAI-SearchBot, ChatGPT-User, PerplexityBot, Claude-SearchBot 등)를 모두 허용한다. AI 학습용 크롤러(GPTBot, ClaudeBot, Google-Extended, CCBot) 허용 여부는 사용자가 정한다. 기본안은 허용(이름이 AI 답에 오르기 쉬워짐).
- sitemap.xml: lastmod와 이미지 정보(image:image)를 넣는다.
- IndexNow: 키 파일과 배포 뒤 알림 스크립트. Bing·네이버·Yandex 등이 바로 다시 수집한다. 구글은 참여하지 않는다.
- llms.txt: 구글은 쓰지 않는다고 공식 안내했다. 다른 AI 서비스용으로 비용이 작아 넣되 효과는 기대하지 않는다.
- 성능 목표(모바일 4G 기준): LCP 2.5초 이하, CLS 0.1 이하, INP 200ms 이하. 첫 화면 이미지만 미리 불러오고(fetchpriority=high), 나머지는 지연 로딩, WebP와 JPEG 대체(AVIF는 만들 도구가 없어 빼 두었다), 모든 이미지에 width·height.
- 글꼴: 한글은 구글 폰트의 분할 전송을 쓰고 `display=swap`. 첫 화면 영문 제목 글꼴(Anton 라틴, 12KB)만 사이트에 직접 두고 미리 불러온다. 늦게 바뀌며 화면이 흔들리는 것(CLS 0.227)을 이것과 줄바꿈 고정으로 0.001까지 줄였다.
- 접근성: lang="ko", 본문 건너뛰기 링크, 대비 4.5:1 이상, 키보드 초점 표시, 모든 이미지 대체 글, 움직임 줄이기 설정 존중.
- 보안 헤더(vercel.json): HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, 콘텐츠 보안 정책.
- 이름·주소는 설정 파일 한 곳(`site.config.json`)에서 바꾼다. 빌드가 모든 페이지, 구조화 데이터, 사이트맵에 반영한다.

## 6. 사용자 계정이 필요한 일 (구현 뒤 안내)

1. Google Search Console: 소유 확인, 사이트맵 제출, '생성형 AI 실적' 보고서로 AI 검색 노출 확인
2. 네이버 서치어드바이저: 소유 확인 메타 태그, 사이트맵 제출, 웹 페이지 수집 요청
3. Bing Webmaster Tools: Search Console에서 가져오기
4. 다음 웹마스터도구: 사이트 등록

## 7. 정할 것

- 최종 주소: 색인은 최종 주소로 시작해야 손실이 없다. Vercel 기본 주소로 먼저 색인되면 나중에 301 이동이 필요하다.
- AI 학습용 크롤러 허용 여부 (기본안: 허용)
- 방문 분석 도구: 지금은 없다. 쿠키 없는 Vercel Web Analytics를 쓸지 정한다. 쓰면 개인정보 처리방침에 적는다.
